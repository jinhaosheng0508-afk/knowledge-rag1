### 中间 50 分钟：DocumentManager

内部使用 `private final List<Document> documents = new ArrayList<>();`。

自己实现以下方法；这里仅列接口，不提供完整答案：

```java
public void addDocument(Document document)
public Document findById(Long id)
public List<Document> searchByTitle(String keyword)
public boolean deleteById(Long id)
public void printAll()
```

为减少纠结，今天统一采用这些规则：

| 输入或情况 | 预期行为 |
|---|---|
| 新增 null 对象、null ID、空白标题 | 抛 IllegalArgumentException，附简短信息 |
| 新增重复 ID | 抛 IllegalArgumentException |
| 按 ID 查询，没找到或传 null | 返回 null |
| 搜索关键词为 null 或空白 | 抛 IllegalArgumentException |
| 标题包含关键词 | 返回匹配列表，今天采用区分大小写匹配 |
| 搜索没有结果 | 返回空列表 |
| 删除成功 | 返回 true |
| 删除不存在的 ID 或传 null | 返回 false |

小提示：

- Long 比较使用 equals，不用 == 比较对象内容。
- 删除可以用下标循环找到后 remove 并立即返回，或使用 Iterator；不要在增强 for 循环中随意修改列表。
- final 限定列表引用，列表里的内容仍可增删。
- 判断标题空白，可以先判断 null，再用 isBlank。
